# Bundled fonts

`DroidSans.ttf` and `DroidSans-Bold.ttf` (Droid Sans, by Google / Ascender Corporation) are licensed
under the Apache License, Version 2.0: https://www.apache.org/licenses/LICENSE-2.0

They are shipped with the app so the generator renders the same text everywhere, including container
images without any system fonts (such as the ones built by `dotnet publish -t:PublishContainer`).
